# Архитектура: ОчисткаДанныхКонвертацииБПУХ

Реализовано по плану `1c-code-architect` (сессия 2026-06-08).

## Подход

Комбинированный: регистр соответствий БСП + типы из BPLM-UHLM.xml + whitelist + dry-run.

## Файлы

| Компонент | Путь |
|-----------|------|
| EPF metadata | `src/ОчисткаДанныхКонвертацииБПУХ.xml` |
| Object module | `src/ОчисткаДанныхКонвертацииБПУХ/Ext/ObjectModule.bsl` |
| Form | `src/ОчисткаДанныхКонвертацииБПУХ/Forms/Форма/` |

## API модуля объекта

- `РазобратьФайлПравил(Путь)` — парсинг XML через `ЧтениеXML`
- `ПостроитьПланУдаления(Настройки)` — идентификация + план
- `ВыполнитьОчистку(План, Настройки, Журнал)` — удаление
- `ПолучитьWhitelistТипов()` — защищённые типы
- `ПодтверждениеКорректно(Текст)` — проверка «УДАЛИТЬ»

## Ограничения MVP

- Fallback по типам без регистра — опасен, выключен по умолчанию
- Топосортировка справочников упрощена (обратный порядок плана)
- Нет фонового задания БСП для больших объёмов
- Маркер загрузки в правилах не реализован (рекомендация на будущее)
