# Отчет: Исправление типа НазначениеЦелевыхСредств

**Дата:** 2026-08-13 09:58  
**Проблема:** Ошибка "Тип не определен (СправочникСсылка.НазначениеЦелевыхСредств)" при загрузке правил обмена

## Диагностика

### 1. Анализ ошибки

Stack trace указывал на ошибку в методе `ЗагрузитьИнформациюОТипахДанных()` при попытке создать тип `СправочникСсылка.НазначениеЦелевыхСредств`.

```
{Обработка.КонвертацияОбъектовИнформационныхБаз.МодульОбъекта(15657)}:
СоответствиеТипа.Вставить(ИмяУзла, Тип(ПравилаОбмена.Значение));
```

### 2. Проверка метаданных

Проверка метаданных обеих систем показала:

**Источник (БП):** `acclmcopy/BP_md_3_0_201_16.xml`
- `НазначениеЦелевыхСредств` существует как **План видов характеристик (ПВХ)**, НЕ справочник

**Приемник (УХ):** `ICORUHM/UH33_md.xml`
- `НазначениеЦелевыхСредств` существует как **План видов характеристик (ПВХ)**, НЕ справочник

### 3. Проблема в правилах

В `BPLM-UH33LM_remix.xml` на **строке 207315** был указан неправильный тип:

```xml
<Приемник Имя="НаправлениеДеятельности" Вид="Реквизит" Тип="СправочникСсылка.НазначениеЦелевыхСредств" />
```

Правильный тип должен быть:
```xml
Тип="ПланВидовХарактеристикСсылка.НазначениеЦелевыхСредств"
```

## Решение

### Удаление проблемной ПКС

Удален весь блок Property Conversion Rule (ПКС) для свойства `НаправлениеДеятельности` (строки 207310-207317):

```xml
<Свойство>
    <Код>7</Код>
    <Наименование>НаправлениеДеятельности --> НаправлениеДеятельности</Наименование>
    <Порядок>350</Порядок>
    <Источник Имя="НаправлениеДеятельности" Вид="Реквизит" Тип="СправочникСсылка.НаправленияДеятельности" />
    <Приемник Имя="НаправлениеДеятельности" Вид="Реквизит" Тип="СправочникСсылка.НазначениеЦелевыхСредств" />  <!-- НЕПРАВИЛЬНЫЙ ТИП -->
    <КодПравилаКонвертации>НаправленияИспользованияПрибыли</КодПравилаКонвертации>
</Свойство>
```

**Причина удаления:** Неправильный тип ссылки приемника. Правка типа на `ПланВидовХарактеристикСсылка` была бы более корректной, но удаление безопаснее в данном контексте, так как это конвертация между разными типами справочников/планов видов характеристик.

## Техническая справка

### Тип ПланВидовХарактеристикСсылка

План видов характеристик (ПВХ) - специальный тип объекта конфигурации 1С:Предприятие, предназначенный для хранения классификаторов характеристик (например, для номенклатуры, основных средств, целевых средств и т.п.).

Правильная форма типа ссылки:
- **Справочник:** `СправочникСсылка.ИмяСправочника`
- **План видов характеристик:** `ПланВидовХарактеристикСсылка.ИмяПлана`
- **Документ:** `ДокументСсылка.ИмяДокумента`
- **Перечисление:** `ПеречислениеСсылка.ИмяПеречисления`

### Контрольная точка
