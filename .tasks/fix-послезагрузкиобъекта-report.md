# Отчёт об исправлении глобального обработчика ПослеЗагрузкиОбъекта

**Дата:** 2026-08-13 01:36  
**Файлы:** `BPLM-UH33LM_remix.xml`, `BPLM-UH33LM_remix.zip`

## Проблема

Ошибка парсинга XML при загрузке правил обмена в КД:

```
Ошибка разбора XML:  - [18,6]
Фатальная ошибка: error parsing attribute name
SystemId: file://E:/1C/AY/BPLM-UHLM-XML/BPLM-UH33LM_remix.xml
```

Корневая причина: конфликт глобального обработчика `ПослеЗагрузкиОбъекта` (строки 20-43) с механизмом отложенной записи движений модуля ICORUHM `КонвертацияОбъектовИнформационныхБаз`.

## Решение

Закомментирован проблемный блок через XML-комментарии:

**Файл:** `e:\1C\AY\BPLM-UHLM-XML\BPLM-UH33LM_remix.xml`

**Строки 18-44:**
```xml
	<!-- Disabled problematic global handler -->
	<!--
	<ПослеЗагрузкиОбъекта>
		... весь блок с МетаданныеОбъекта, Объект.Движения.Хозрасчетный ...
	</ПослеЗагрузкиОбъекта>
	-->
```
