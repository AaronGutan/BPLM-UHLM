# Phase 3: Уточнения и принятые решения

Уточняющие вопросы пользователю были предложены, но пропущены. Решения приняты по умолчанию на основе анализа конфигурации и утверждённого плана.

## Принятые решения
1. **Целевая конфигурация**: `e:\1C\AY\acclmcopy` (явно указана пользователем как `@acclmcopy`).
2. **Имя плана обмена**: `Консолидация` (явно указано пользователем).
3. **Состав документов**: документы с движениями по `AccountingRegister.Хозрасчетный`, исключая объекты с префиксом `Удалить` (устаревшие объекты типовой конфигурации).
4. **Состав справочников**: объединение справочников-субконто и справочников-реквизитов документов; типы `CatalogRef.*`; исключены `Удалить*`.
5. **AutoRecord**: `Enable` для всех объектов состава (авторегистрация изменений — основная цель задачи).
6. **Дополнительно в состав**: `ChartOfAccounts.Хозрасчетный` и `ChartOfCharacteristicTypes.ВидыСубконтоХозрасчетные` (источники данных консолидации).
7. **Реквизит плана обмена**: `РегистрироватьИзменения` (Boolean) — по типовому паттерну планов обмена БП.

## Технические замечания
- План обмена создаётся как собственный (Native) объект расширения.
- Состав ссылается на объекты основной конфигурации по именам метаданных (заимствование объектов в расширение не требуется для регистрации изменений их через собственный план обмена расширения).
