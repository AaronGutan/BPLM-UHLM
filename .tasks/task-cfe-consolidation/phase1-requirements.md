# Phase 1: Требования

## Исходный запрос
Создать расширение конфигурации для БП (`@acclmcopy`), которое реализует:
- регистрацию изменений документов, у которых есть движения по регистру бухгалтерии "Хозрасчетный";
- регистрацию изменений справочников, которые являются субконто или реквизитами этих документов.

План обмена назвать **Консолидация**.

## Ключевые требования
1. Целевая конфигурация: `e:\1C\AY\acclmcopy` (Бухгалтерия Предприятия КОРП).
2. Создаётся расширение конфигурации (CFE), а не правка основной конфигурации.
3. Новый объект расширения: план обмена `Консолидация`.
4. Состав плана обмена:
   - Документы с движениями по `AccountingRegister.Хозрасчетный` (исключая объекты с префиксом `Удалить`).
   - Справочники-субконто из `ChartOfCharacteristicTypes.ВидыСубконтоХозрасчетные` (типы `CatalogRef.*`).
   - Справочники-реквизиты документов (типы `CatalogRef.*`, встречающиеся в метаданных документов).
5. Для всех объектов состава: `AutoRecord=Enable` (авторегистрация изменений).

## Ограничения
- Без использования Python (правило проекта).
- Соблюдение стандартов 1С.
- Изменения в основной конфигурации не вносятся.
