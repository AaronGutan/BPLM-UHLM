# Phase 0: Оценка сложности

## Задача
Создать расширение конфигурации (CFE) для БП (`e:\1C\AY\acclmcopy`) с новым планом обмена "Консолидация", регистрирующим изменения:
- всех документов с движениями по регистру бухгалтерии "Хозрасчетный";
- справочников, являющихся субконто регистра "Хозрасчетный" или реквизитами этих документов.

## Оценка сложности: Средняя

Обоснование:
- Объект один (план обмена), но состав большой (~117 документов + ~77 справочников).
- Требуется точное извлечение состава из метаданных конфигурации.
- Технический риск: план обмена создаётся как собственный объект расширения, состав ссылается на объекты основной конфигурации.
- Нет написания бизнес-логики на встроенном языке — только декларативные метаданные.
