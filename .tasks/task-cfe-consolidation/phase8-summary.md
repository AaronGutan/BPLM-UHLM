1. План обмена — собственный объект расширения; сериализуется как обычный объект (без `ObjectBelonging`). Подтверждено образцом `DNA_Dashboard/HTTPServices/unloading_debt.xml`.
2. Имя `Консолидация` не совпадает с префиксом расширения `Консолидация_` — допустимо: платформа разрешает собственные объекты без префикса (образец: `HTTPService.unloading_debt` в расширении с префиксом `DD`).
3. Значение авторегистрации — `Allow` (не `Enable`), namespace состава — `http://v8.1c.ru/8.3/xcf/extrnprops`. Сверено с типовыми планами обмена конфигурации.
