# Инструкция: сверка оборотов регистра Хозрасчётный (EMS)

Инструмент: обработка **HTTPВыборка** (подсистема EMS).

Сверка сравнивает обороты `РегистрБухгалтерии.Хозрасчетный` в текущей (локальной) базе и во внешней (источнике / приёмнике — в зависимости от того, откуда вы открыли обработку). Результат — список **регистраторов** (документов), по которым обороты не совпали.

---

## Подготовка

1. Расширение **EMS** установлено в обеих базах, участвующих в сверке.
2. Настроена связь с внешней базой:
   - через COM (форма `COMСоединение`), или
   - через HTTP (параметры в `EMS_ПараметрыБаз`, сервис `ЦТ_HTTP_Сверка` на стороне внешней базы).
3. Заполнены соответствия объектов обмена (иначе ссылки организаций/субконто могут не сопоставиться).
4. Есть права на чтение регистра бухгалтерии и работу с обработками EMS.

---

## Как открыть

1. Запустите 1С (обычно базу-приёмник УХ).
2. Раздел **EMS**.
3. Откройте обработку **HTTPВыборка**.

---

## Пошаговая сверка Хозрасчётный

### 1. Укажите период

В поле **Период** задайте интервал сверки (дата начала и окончания).

Без периода сверка оборотов не запустится.

### 2. Укажите организацию

В группе **Организация**:

- **ИД** (`ВыборкаОргИД`) — ссылка на организацию (или идентификатор, по которому строится условие `Организация В ИЕРАРХИИ`).
- Реквизит организации для обычной выборки объектов здесь для оборотов Хозрасчётный не нужен — фильтр идёт по параметру организации в запросе оборотов.

### 3. Выберите объект сверки

Вариант А — таблица метаданных:

1. В таблице **ВыборкаМетаданные** найдите строку с типом/видом Хозрасчётный  
   (например `РегистрыХозрасчетный` или `РегистрБухгалтерии` / `Хозрасчетный`).
2. Установите флажок **Выбор** у этой строки.
3. Остальные строки лучше снять (**Снять все**, затем отметить нужную).

Вариант Б — поля сверху формы:

- **Тип**: `РегистрыХозрасчетный`  
  (или `РегистрБухгалтерии` / `РегистрыБухгалтерии` при **Вид** = `Хозрасчетный`)
- **Вид**: `Хозрасчетный` (если выбран тип «РегистрБухгалтерии»)

### 4. Режим сверки

Переключатель режима:

| Значение | Что делает |
|----------|------------|
| **Обороты** | Сравнивает обороты по ключам строк регистра |
| **База → Разница** | Показывает только расхождения (рекомендуется) |
| **База → Локальная** | Только данные текущей базы |
| **База → Внешняя** | Только данные внешней базы |

Для поиска расхождений: **Обороты** + **Разница**.

### 5. Стороны разницы (Лево / Право)

| Флажок | Смысл метки в сообщениях |
|--------|---------------------------|
| **Лево** | Есть в локальной, нет во внешней (`Л<В`) |
| **Право** | Есть во внешней, нет в локальной (`В<Л`) |

Для полной сверки включите оба флажка.

### 6. Формат результата

Для оборотов Хозрасчётный удобно:

- **Выборка** — подробный вывод в окно сообщений;
- **Ссылки** — список регистраторов-расхождений;
- **Количество** — только число расхождений (быстрая проверка «есть/нет»).

### 7. Запуск

Нажмите **Выбрать**.

В окне сообщений увидите:

- объёмы выборок локальной и внешней базы (`Л …, В …`);
- строки расхождений с префиксами `Л<В` / `В<Л`;
- итог `Разниц: N`.

Результат по Хозрасчётному — **регистраторы** (документы), а не построчная ОСВ.

---

## Как читать результат

1. `Л<В` — проводки/обороты есть локально, во внешней базе такой строки нет (или ключ не совпал).
2. `В<Л` — есть во внешней, локально нет.
3. Откройте документ-регистратор и сравните движения по Хозрасчётному вручную (или догрузите документ через обмен).
4. Типичные причины расхождения:
   - документ не проведён / не выгружен;
   - другой период или организация;
   - не сопоставлены ссылки (субконто, подразделение);
   - разная аналитика (Субконто1–3, КорСчет).

---

## Что сравнивается «под капотом»

По каждой строке оборотов ключ включает примерно:

Организация, Подразделение, Счет, Субконто1–3, КорСчет, Регистратор, суммы Дт/Кт (БУ, НУ, ПР, ВР).

Запрос строится к `РегистрБухгалтерии.Хозрасчетный.Обороты` за указанный период по организации (с иерархией).

---

## Типичные ошибки

| Сообщение / ситуация | Что сделать |
|----------------------|-------------|
| «Не задан период выборки оборотов» | Заполнить **Период** |
| «Не задан ИД организации» | Указать организацию в **ВыборкаОргИД** |
| «Отметьте строку в таблице метаданных…» | Отметить Хозрасчётный или заполнить Тип/Вид |
| Пустая разница при ожидаемых расхождениях | Проверить период, организацию, соответствия ссылок, подключение к внешней базе |
| Ошибка COM / подключения | Открыть и настроить `COMСоединение` или HTTP-параметры базы |

---

## Краткая шпаргалка

1. EMS → **HTTPВыборка**
2. Период + организация
3. Отметить Хозрасчётный (или Тип = `РегистрыХозрасчетный`)
4. Режим: **Обороты**, база: **Разница**, Лево+Право
5. **Выбрать**
6. Разобрать регистраторы из списка расхождений
