# Что создать в конфигураторе (вы), что вставлю я

## Сейчас в файлах CFE

Минимальный каркас (должен грузиться без XML-ошибок):

- `Configuration.xml` — `КонсолидацияУХ`, префикс `CncdUH_`, AddOn
- `Language.Русский` (заимствование)
- `Role.CncdUH_ОсновнаяРоль`
- `CommonModule.ОбменДаннымиПереопределяемый` — уже с `&После("ПолучитьПланыОбмена")`

План обмена, форма, команды, макеты **убраны из XML** — создаёте их в конфигураторе.

Готовые тексты модулей: `modules-to-paste/`.

## Чеклист в конфигураторе (расширение КонсолидацияУХ)

### 1. План обмена `Консолидация`

| Свойство | Значение |
|----------|----------|
| Имя | `Консолидация` |
| Распределённая ИБ | **Нет** |
| Длина кода | 9 (переменная) |
| Длина наименования | 100 |

**Реквизиты** (как на БП):

- `ДатаНачалаВыгрузкиДокументов` — Дата
- `ИспользоватьОтборПоОрганизациям` — Булево
- `РежимВыгрузкиОбъектов` — `ПеречислениеСсылка.РежимыВыгрузкиОбъектовОбмена`
- `РежимВыгрузкиПриНеобходимости` — то же перечисление

**ТЧ `Организации`:** реквизит `Организация` → `СправочникСсылка.Организации`

**Состав:** пока можно пустой или точечно. Для всех объектов **Авторегистрация = Запретить**.

**Макеты** (тип Текстовый документ), имена:

- `ПравилаОбмена`
- `ПравилаОбменаКорреспондента`
- `ПравилаРегистрации`

Правила можно позже скопировать из BP-CFE (`acclmcopy-cfe-consolidation/.../Templates/`).

### 2. Форма `ФормаУзла`

Управляемая форма объекта плана. Сделать элементами (имена важны для кода):

- `Код`, `Наименование`
- `ПояснениеЭтотУзел`, `ПояснениеКорреспондент` (надписи)
- `ГруппаОграниченияРегистрации`
- `ИспользоватьОтборПоОрганизациям` + обработчик `ПриИзменении`
- таблица `Организации`

Назначить основной формой объекта.

### 3. Заимствования БСП (по желанию, для UI синхронизации)

- Общий модуль уже есть.
- Группа команд `СинхронизацияДанных` + общие команды (`Синхронизировать` и др.) — лучше **заимствовать из УХ** в конфигураторе (не копировать из БП).

### 4. После создания — выгрузить XML / сказать мне

Я вставлю логику из `modules-to-paste/`:

| Файл | Куда |
|------|------|
| `ExchangePlan_ManagerModule.bsl` | модуль менеджера плана |
| `ExchangePlan_ObjectModule.bsl` | модуль объекта плана |
| `Form_ФормаУзла_Module.bsl` | модуль формы |
| `CommonModule_...bsl` | уже в каркасе |

Опционально после выгрузки: подправить `Content.xml`, макеты правил.

## Сборка

`cfe-build` с `-RecreateExtension` для текущего каркаса — должна пройти.
Затем работаете в конфигураторе поверх загруженного расширения и снова выгружаете XML.
