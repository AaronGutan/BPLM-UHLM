# Загрузка правил на УХ (ошибка Правила[Валюты])

## Почему

При загрузке сообщения с БП платформа ищет ПКО в **правилах корреспондента** узла.
Если там пустая заглушка УХ→БП, ПКО `Валюты` нет → ошибка
`Правила["Валюты"]` / «Поле объекта не обнаружено (Валюты)».

В `BPLM-UH33LM_remix.xml` ПКО `Валюты` есть. Нужно попасть в правильный слот на УХ.

## Загрузка через UI — только ZIP

«Загрузить комплект правил» принимает архив `*.zip`, не голый XML.

Готовый комплект: **`BPLM-UH33LM_remix.zip`** (корень репозитория).

Состав:
- `ExchangeRules.xml` — remix (БП→УХ)
- `CorrespondentExchangeRules.xml` — тоже remix (чтобы на УХ был ПКО `Валюты`)
- `RegistrationRules.xml` — из `BPLM-UHLM.zip`

### Шаги
1. Синхронизация **БП – УХ Консолидация** → **Загрузить комплект правил**.
2. Указать `BPLM-UH33LM_remix.zip`.
3. Загрузить на **УХ** и на **БП**.
4. Повторить обмен.

## Макеты CFE (поставка)

В `_load-bisect-backup` макеты `ПравилаОбмена` и `ПравилаОбменаКорреспондента`
тоже заменены на remix (рядом `.bak-...`). Для живой базы достаточно ZIP выше.
