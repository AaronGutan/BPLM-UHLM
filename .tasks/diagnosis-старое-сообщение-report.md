# Диагностика: Ошибка "Тип не определен (НазначенияИспользования)"

**Дата:** 2026-08-13 09:27  
**Ошибка:** `Тип не определен (СправочникСсылка.НазначенияИспользования)`  
**Место:** `{Обработка.КонвертацияОбъектовИнформационныхБаз.МодульОбъекта(7423)}:ЗагрузитьИнформациюОТипахДанных()`

### БП (источник) - BP_md_3_0_201_16.xml
- ✅ `НазначенияИспользованияНоменклатуры` - ЕСТЬ
- ✅ `НазначенияИспользованияНМА` - ЕСТЬ
- ❌ `НазначенияИспользования` (без окончания) - НЕТ

### УХ (приёмник) - UH33_md.xml
- ✅ `НазначенияИспользованияНоменклатуры` - ЕСТЬ
- ✅ `НазначенияИспользованияНМА` - ЕСТЬ
- ❌ `НазначенияИспользования` (без окончания) - НЕТ

**Вывод:** Справочник `НазначенияИспользования` **НЕ СУЩЕСТВУЕТ** ни в БП, ни в УХ!

## Анализ правил обмена

### Проверка BPLM-UH33LM_remix.xml (актуальная версия)

```bash
Grep: "СправочникСсылка\.НазначенияИспользования\""
Результат: No matches found ✅

Результат: No matches found ✅
```

**Вывод:** В правилах обмена НЕТ ссылок на несуществующий тип `НазначенияИспользования`!

## Корневая причина

Ошибка возникает на этапе **загрузки сообщения обмена**, а не правил конвертации:

```
{Обработка.КонвертацияОбъектовИнформационныхБаз.МодульОбъекта(7423)}:ЗагрузитьИнформациюОТипахДанных();
{Обработка.КонвертацияОбъектовИнформационныхБаз.МодульОбъекта(2421)}:НачатьЧтениеСообщения(ЧтениеСообщения);
```

**Проблема:** Старое сообщение обмена (XML-файл обмена) было создано **ДО** исправления правил (2026-08-13) и содержит информацию о типе `СправочникСсылка.НазначенияИспользования`.

**Почему так произошло:**
1. В правилах были 4 ПКС, где тип приёмника был указан как `СправочникСсылка.НазначенияИспользования` (строки 390707-390712, 391464-391469, 440876-440882, 440946-440951)
2. С этими правилами был выполнен обмен и создано сообщение обмена
3. Это сообщение было сохранено в каталоге обмена
4. Правила были исправлены (ПКС удалены)
5. При попытке загрузить **старое** сообщение с новыми правилами возникает ошибка: сообщение содержит тип, которого нет ни в правилах, ни в конфигурации

## Решение

### Шаг 1: Удалить старое сообщение обмена

**В базе УХ (приёмник):**

**Вариант A (через интерфейс):**
1. `Администрирование → Обмен данными → Мониторинг обмена данными`
2. Найти узел обмена с БП
3. Вкладка "Сообщения обмена"
4. **Удалить** все сообщения в очереди

**Вариант B (через файловую систему):**
1. Найти каталог обмена (обычно в `\\server\exchange\` или локальный путь)
2. Удалить все XML-файлы сообщений для данного узла обмена
3. Удалить все файлы с расширением `.tmp` и `.processing`

### Шаг 2: Убедиться, что правила перезагружены

**В базе БП (источник):**
- `Конвертация данных 2.1` → Загрузить правила **ВЫГРУЗКИ**
- Файл: `BPLM-UH33LM_remix.zip`
- Дата: 2026-08-13 02:15 или позже

**В базе УХ (приёмник):**
- `Конвертация данных 2.1` → Загрузить правила **ЗАГРУЗКИ**
- Файл: `BPLM-UH33LM_remix.zip`
- Дата: 2026-08-13 02:15 или позже

### Шаг 3: Запустить обмен заново

- Запустить выгрузку из БП
- Новое сообщение будет создано с корректными правилами
- Загрузить сообщение в УХ
- Ошибка о типе `НазначенияИспользования` больше не возникнет

## Проверка результата

После выполнения шагов проверить:

- ✅ Документы передаются
