# Отчёт об исправлении типа НазначенияИспользования

**Дата:** 2026-08-13 02:15  
**Файлы:** `BPLM-UH33LM_remix.xml`, `BPLM-UH33LM_remix.zip`

## Проблема

Ошибка при загрузке правил обмена в приёмник (УХ):

```
Тип не определен (СправочникСсылка.НазначенияИспользования)
{Обработка.КонвертацияОбъектовИнформационныхБаз.МодульОбъекта(15657)}:СоответствиеТипа.Вставить(ИмяУзла, Тип(ПравилаОбмена.Значение));
```

Корневая причина: В правилах обмена указан тип `СправочникСсылка.НазначенияИспользования`, который **не существует** в конфигурации УХ (приёмник).

## Анализ

В правилах обмена найдено 4 ПКС (правила конвертации свойств), которые сопоставляют:

**Источник (БП):** `СправочникСсылка.НазначенияИспользованияНоменклатуры`  
**Приёмник (УХ):** `СправочникСсылка.НазначенияИспользования` ← **не существует!**

### Найденные проблемные ПКС:

1. **Строки 390707-390712:** Свойство `СпецМатериалНазначениеИспользования` (документ)
2. **Строки 391464-391469:** Свойство `СпецМатериалНазначениеИспользования` (другой контекст)
3. **Строки 440876-440882:** Свойство `НазначениеИспользования` (табличная часть `Спецодежда`)
4. **Строки 440946-440951:** Свойство `НазначениеИспользования` (другой контекст)

### Проверка метаданных УХ:

Запрос в `UH33_md`:
```
Grep: "НазначенияИспользования"
Результат: No files with matches found
```

Справочник `НазначенияИспользования` **отсутствует** в конфигурации УХ.

## Решение

Удалены все 4 проблемных блока ПКС из правил обмена.

**Причина удаления:** Справочника нет в УХ → свойства всё равно не могут быть заполнены → безопасно удалить.

**Альтернатива (не использована):** Заменить тип на примитивный `Строка` - но это создаст несоответствие типов данных.
